# Placement Tracker (MERN)

A full-stack application to manage and track job applications.

## 🛠 Tech Stack
- React
- Node.js
- Express.js
- MongoDB

## Features
- Add applications
- View applications
- Update status
- Delete applications

## Run Project

### Backend
cd backend
npm install
npm start

### Frontend
cd frontend
npm install
npm start
